## Разделы

| Раздел | Для чего |
|---|---|
| **Рабочие дни** | Учёт времени по задачам, итоги дня, отчёты |
| **TO-DO** | Канбан-доски по проектам с вложенными досками |
| **Таймер** | Обратный отсчёт со звуковыми сигналами |
| **Граф знаний** | Заметки, связанные `[[вики-ссылками]]`, и их визуальный граф |
| **Трекер** | Рутины, привычки, разовые задачи и бюджеты времени |
| **Нетворкинг** | Личная CRM: контакты, карта сети, встречи, цели, организации |

Любой раздел можно скрыть из боковой навигации в настройках.


## Возможности

### Рабочие дни
> - Запуск и остановка отсчёта времени по каждой задаче - видно, сколько ушло на каждую.
> - Панель актуальных задач держит в фокусе самые важные; из неё задачу можно добавить в день одним кликом.
> - Итоги, планы и вопросы по каждому дню.
> - Отчёты за день или за несколько дней: PNG, TXT и Markdown.

### TO-DO
> - Канбан-доски по проектам: колонки, карточки, перетаскивание, сворачивание колонок.
> - Вложенные доски внутри карточки для декомпозиции крупных задач.
> - Архив проектов.

### Таймер
> - Обратный отсчёт с паузой и продолжением; не входит в учёт рабочего дня.
> - 15 встроенных сигналов и загрузка своих звуков, настройка громкости и длительности.
> - Плавающий виджет с оставшимся временем виден в других разделах.
> - История запусков.

### Граф знаний
> - Заметки со связями через `[[вики-ссылки]]`, исходящие и обратные ссылки.
> - Интерактивный граф связей и поиск по заметкам.
> - Импорт проектов и карточек из TO-DO по кнопке.

### Трекер
> - Расписания: каждый день, по дням недели, N раз в неделю, раз в N дней, разовая задача к дате.
> - Количественные цели с единицами измерения («8 стаканов», «30 страниц»).
> - «Песочные часы» - дневной бюджет времени, который тратится по таймеру.
> - Серии (streaks) и история выполнения.

### Нетворкинг
> - **Контакты** - подробное досье: круги, роли, этап отношений, произвольные поля, фото, история касаний.
> - **Ритм связей** - напоминания «пора связаться» по приоритетным спискам, дни рождения и праздники с упреждением.
> - **Карта сети** - интерактивная визуализация людей, групп интересов и связей по сферам жизни, экспорт в PNG.
> - **Встречи** - подготовка, разбор и оценка динамики отношений.
> - **Цели** - круг жизненных целей и люди, которые помогают их достичь.
> - **Организации** - карты подразделений, групп влияния и связей внутри компаний и сообществ.
> - **Каталоги** - что могу предложить, поводы для контакта, места для знакомств, наставники.
> - **Помощники** - сортировка новых контактов, первый контакт, диагностика отношений, план встречи с гостями, ежемесячный разбор сети.
> - **Импорт/экспорт** - импорт из CSV и vCard с предпросмотром и дедупликацией; выгрузка в CSV и Markdown.
> - **Приватность** - PIN-код на раздел, маскировка конфиденциальных полей, исключение их из выгрузок.


## Программа для Windows

Готовый файл `TimeKeeper.exe` публикуется отдельным релизом: https://github.com/codemed7-git/TimeKeeper/releases

Скачайте `TimeKeeper.exe` и запустите его. Откроется браузер по адресу http://127.0.0.1:7777/. Чтобы остановить программу, закройте окно консоли.

Рядом с exe появляются ваши данные: база `timekeeper.db` и папка `user_data` (свои звуки таймера и фото контактов). Они остаются на компьютере и не входят ни в репозиторий, ни в файл программы.

Собрать exe из исходников:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt pyinstaller
venv\Scripts\pyinstaller.exe --noconfirm TimeKeeper.spec
```

Файл появится в `dist\TimeKeeper.exe`.


## Установка из исходников

```bash
git clone https://github.com/codemed7-git/TimeKeeper.git
cd TimeKeeper

python -m venv venv

venv\Scripts\activate

source venv/bin/activate

pip install -r requirements.txt

python app.py
```

Откройте браузер и перейдите по адресу: http://127.0.0.1:7777/
